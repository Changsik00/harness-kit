`docs/wiki/` 의 **지식이 맞는가**를 점검합니다. 구조(고아 링크·신선도)와 기계 검증 가능한 사실(`verify` 마커 표, 경로 존재, 크기 상한)은 `sdd doctor` 가 이미 결정론적으로 검사하므로, 이 명령은 **사람/LLM 판단이 필요한 의미 수준**만 다룹니다.

> **이 명령은 파일을 수정하지 않는다.** 보고서만 출력한다. 고칠지는 사용자가 정하고, 갱신은 별도로 `schema.md` 규약(제자리 갱신 + 변경 이력, 충돌 시 사용자 확인)에 따라 한다.

## 1. 결정론 결과 먼저 확인

```bash
bash .harness-kit/bin/sdd doctor
```

`wiki layer` 섹션의 **사실 검증(W-5)** 경고가 있으면 보고서 맨 앞에 그대로 옮긴다. 이 항목은 코드가 사실의 출처이므로 wiki 가 틀린 것이다. 신선도(`wiki 낡음(보조)`)는 보조 신호로만 다룬다.

## 2. 대상 페이지 읽기

`docs/wiki/direction.md`, `docs/wiki/components/*.md`, `docs/wiki/threads.md`(있으면)를 읽는다. 출처별 로그(`decisions.md`, `patterns.md`)는 모순 대조용으로만 참고한다. 인자로 페이지가 주어지면 그 페이지만.

## 3. 점검 항목

각 지적에는 **페이지 · 줄 · 근거(인용 또는 파일)** 를 반드시 붙인다. 근거를 대지 못하는 항목은 올리지 않고, 확신이 낮으면 `(추정)` 으로 표시한다.

1. **모순** — 같은 주제에 서로 어긋나는 주장이 한 페이지 안에 또는 페이지 사이에 있다 (예: direction 은 "수용", components 는 "미결").
2. **대체됐는데 현재형** — `변경 이력` 에 "A → B" 로 바뀌었다고 적혀 있는데 `현재 설계` 가 여전히 A 를 말한다. 또는 ADR/코드에서 이미 바뀐 입장이 현재형으로 남아 있다.
3. **장기 보류 · 반복** — `반복·미결` / `열린 질문` / `⚠ 충돌 대기` 항목이 **날짜 근거로** 오래(권장: 3개월 이상) 같은 상태다. 같은 문제가 `변경 이력` 에 3번 이상 나온다. 날짜를 확인하지 못하면 올리지 않는다.
4. **출처 없는 사실 주장** — 파일·spec·ADR 출처가 없고 `(미확인)` 표시도 없는 사실 서술. 해석에는 "판단" 표시가 있어야 한다.
5. **`verify` 마커 누락** — 코드에서 기계적으로 확인할 수 있는 표·목록(hook 기본 모드, 서브커맨드 목록 등)인데 바로 위에 `<!-- verify: <키> -->` 가 없다. 지원하는 키가 아직 없으면 "검증기 후보" 로 표시.

## 4. 보고서 형식

```
🔍 wiki 의미 lint  (대상 N페이지)

[사실 검증 — doctor]  (없으면 "불일치 0건")
  - <doctor 경고 그대로>

[의미 점검]
  1. 모순 (K)
     - <페이지>:<줄> ↔ <페이지>:<줄> — <한 줄> (근거: "…")
  2. 대체됐는데 현재형 (K)
  3. 장기 보류 · 반복 (K)
  4. 출처 없는 주장 (K)
  5. verify 마커 누락 (K)

(추정) 표시 N건 — 사람이 판단 필요

다음: 고칠 항목을 알려 주세요. 갱신은 schema.md 규약(변경 이력 보존, 충돌은 사용자 확인)으로 진행합니다.
```

지적이 하나도 없으면 `의미 점검 이상 없음` 이라고만 쓴다. 억지로 채우지 않는다.

## 5. 하지 않는 것

- 페이지 수정, 커밋, `log.md` 기록 (점검은 인제스트 이벤트가 아님)
- 근거 없는 추측을 사실처럼 보고
- 결정론 검사가 이미 잡는 항목(고아 링크, 경로 존재, 크기)을 다시 세기
